Como obter meu código?

O responsável pelo Cogniva emite um código de uso único, válido por 10 minutos, para uma conta autorizada. No ambiente do backend:

app --issue-web-code ID_DA_CONTA

Use a mesma conta do Android para administrar seus concursos. O código não é seu ID ou nome de usuário.
